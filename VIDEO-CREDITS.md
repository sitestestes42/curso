# Video register

Every video embedded in AI Website Launch, with the evidence behind it. Checked on **2026-10-15**.

## How to read this
- **What was actually verified:** each video was found through web search, then checked with YouTube's official oEmbed endpoint. That confirmed the video exists, who published it, and that it returned embed metadata (YouTube returns an error for private or non-embeddable videos).
- **What was NOT verified:** playback in a browser, video duration, and each video's license label. The environment used to build this has no access to YouTube itself.
- **Legal basis:** these are standard YouTube embeds through the official player (youtube-nocookie.com). Nothing is downloaded, copied, re-hosted or modified. Embedding relies on the owner having left embedding enabled, and the owner can disable it at any time. **None of these videos is claimed to be copyright-free or licensed for reuse.**
- **Commercial use:** this course is sold, so videos under non-commercial licenses (for example CC BY-NC) must not be used. None of the embedded videos was selected on the basis of a reuse license.
- **Before launch:** open every lesson once and confirm each video plays, is still available and still matches the lesson.
